# 🚀 Cara Menggunakan

1. Clone repository

```bash
git clone https://github.com/andrast32/python-coding_9B.git
```

2. Masuk ke folder project

```bash
cd python-coding_9B
```

3. Jalankan file Python

```bash
python nama_file.py
```

atau

```bash
python3 nama_file.py
```
